# aldorodriguez.com.ar

Portfolio personal de Aldo Rodriguez, desarrollador full stack.

Sitio: [aldorodriguez.com.ar](https://aldorodriguez.com.ar)

## Stack

- [Astro](https://astro.build) con TypeScript en modo estricto
- Tailwind CSS
- Íconos de Tabler
- Sitemap y datos estructurados para SEO

## Desarrollo

```sh
pnpm install
pnpm dev       # servidor local
pnpm build     # build de producción en dist/
pnpm preview   # previsualizar el build
pnpm lint      # astro check
pnpm test      # vitest
```

Los proyectos se cargan como archivos Markdown en `src/content/proyectos/`.
